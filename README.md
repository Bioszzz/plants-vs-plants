# 植物斗争

一个植物对战卡牌游戏，纯 Python 标准库实现，**零第三方依赖**。

这个包是**最小可运行集合**：只有跑起来需要的代码、网页资源和启动脚本。
规则文档、开发笔记不随包发布。

- 需要 **Python 3.9 或更高**（纯标准库，不需要装任何东西，也不需要 tkinter）
- 不需要 `pip install` 任何东西

---

## 一、双击就能玩（推荐）

四个 `.bat` 都会自己找 Python，不用配 PATH。

| 脚本 | 干什么 |
|---|---|
| `网页版.bat` | **浏览器客户端**。打开后可以「本机开一局」和电脑打，也可以填服务器 IP 加入别人的对局。 |
| `房主控制台.bat` | **只观战的房主**。开一局等你连，自己在控制台页面看战报和场面，不下场。把本机 IP 告诉玩家即可。 |
| `多开试玩台.bat` | **一台机器开多个真人座位**。在配置页上设人数 / 电脑数 / 开局种子 / 规则集 / 每个座位的名字，点「一键开局」会弹出 N 个浏览器标签，每个标签是一个独立玩家 —— **想同屏双人对打就用它**（人数填 2、电脑填 0）。 |
| `检查更新.bat` | **检查并自动安装最新版**。查到新版会问一句，回车就开始下载、校验、备份、覆盖。 |

端口：网页客户端 8000 起、房主控制台 8090 起、试玩台配置页 8300 起，被占用会自动往后找。

> **非 Windows（Linux / Android Termux）**：`.bat` 一个都跑不了 —— 那是 cmd.exe 的脚本语言。
> 试玩台和检查更新各有一个等价脚本：
>
> ```sh
> sh 多开试玩台.sh     # = python playtest.py
> sh 检查更新.sh       # = python updater.py
> ```
>
> 网页版与房主控制台没有对应 `.sh`，直接 `python webui.py` / `python netserver.py`。
> ⚠️ 试玩台只监听 `127.0.0.1`，所以手机上必须**跑在手机自己身上**；跨设备联机走 `netserver.py`。

## 二、手动运行

```bash
python main.py                      # 控制台热座（最简）
python webui.py                     # 浏览器客户端
python netserver.py 2 1 8080 7      # 开服：2 人、1 个电脑、端口 8080、开局种子 7
python netclient.py                 # 终端客户端
python playtest.py                  # 多开试玩台（配置页 + N 个座位）
python updater.py                   # 检查并更新到最新版（--check 只查不装）
```

`netserver.py` 参数：`[人数] [电脑数] [端口] [开局种子]`

- 不带 `--keep`：打完一局服务端就退出
- 带 `--keep`：打完一局**不退出**，玩家点「再来一局」重连同一端口就是下一局
- `--open`：开服并自动打开房主控制台页面

## 三、联机怎么玩

1. 房主在自己机器上双击 `房主控制台.bat`（或运行 `python netserver.py 2 0`）。
2. 房主查本机 IP（`ipconfig`），告诉玩家。
3. 玩家双击 `网页版.bat`，在「服务器 IP」里填那个地址，点连接。
4. 人齐了自动开局。

同机测试更省事：直接双击 `多开试玩台.bat`。

## 四、文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 控制台热座入口 |
| `engine.py` | 规则引擎（回合流程、结算顺序、胜负） |
| `plants_data.py` | 所有植物的数值与规则字段 |
| `webui.py` / `netserver.py` | 网页客户端 / 联机服务端 |
| `netproto.py` | 消息协议 |
| `netclient.py` | 终端客户端 |
| `playtest.py` | 多开试玩台 |
| `updater.py` | 自动更新器（网页里的「立即更新」和 `检查更新.bat` 都走它） |
| `bots.py` / `console_ui.py` | 电脑玩家 / 控制台界面 |
| `web/` | 网页版前端（HTML / CSS / JS） |
| `VERSION` | 版本号，界面显示和「检查更新」用它，删掉会显示"未知" |
| `names.json` | 你上次用的名字，自动生成，可以删 |
| `_backup/` | 更新前自动备份的旧文件，确认新版没问题后可以删 |

## 五、怎么更新

两种方式，做的是同一件事：

1. **在网页里**：打开网页版 → 左下角「版次」旁边点「检查更新」→ 有新版会出现
   「立即更新到 vX.Y」→ 点它。
2. **双击 `检查更新.bat`**：终端里会问一句「要更新到 vX.Y 吗？」，回车就开始。

更新器会：查 Gitee 上的公开发行版 → 下载 zip → **校验**（路径不许越界、关键文件
必须齐全、解压后真跑一次 `import`）→ 把要覆盖的旧文件备份到 `_backup/v旧_时间戳/`
→ 逐个覆盖。

- 只覆盖包里那 24 个文件，**`names.json` 和你的其它东西一概不碰**。
- 如果文件夹名里带着旧版本号（如 `plant-vs-plant-v0.72`），更新完会**在窗口关掉后**
  自动改成新版本号；你自己起的名字（如「植物斗争」）不会被改。
- **更新完必须关掉程序重新打开** —— 现在跑的仍然是旧代码。
- 万一新版有问题：把 `_backup/` 里那份拷回去就行。
